# SupportCourses — Formations informatique, du développement web au Cloud

Supports gratuits qui accompagnent la chaîne YouTube : cours en PDF, slides, cahiers d'exercices, corrigés et code.
Chaque parcours suit l'ordre des vidéos ; les parcours sont publiés au fur et à mesure.

## Les parcours

| # | Parcours | Contenu | État |
|---|---|---|---|
| 01 | [Développement web](01-developpement-web/) | Bases de données et SQL, HTML5, CSS3, JavaScript, PHP et MySQL | En cours |
| 02 | Systèmes et réseaux | Linux, Windows Server, Active Directory, réseaux TCP/IP, virtualisation Proxmox | À venir |
| 03 | DevOps | Git, Docker, Ansible, Terraform, Kubernetes, CI/CD, supervision (Prometheus, Grafana, ELK) | À venir |
| 04 | Cloud et certifications | AWS (Cloud Practitioner, Solutions Architect, SysOps, DevOps), Azure (AZ-900, AZ-104, AZ-400) | À venir |
| 05 | Automatisation et IA | n8n, automatisation des processus, IA appliquée | À venir |

## Comment utiliser ces supports

1. Regarde la vidéo de la séance.
2. Lis le support PDF correspondant.
3. Fais les exercices du cahier d'exercices.
4. Les corrigés sont ajoutés au fil de l'avancement dans `corriges/`.

## Télécharger

Bouton vert **Code** → **Download ZIP**, ou :

```bash
git clone <URL-de-ce-dépôt>
```

Pour importer la base d'exemple : phpMyAdmin → Importer → `01-developpement-web/1-bases-de-donnees/code/bibliotheque_lycee.sql`.
