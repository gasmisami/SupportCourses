# Cours de développement web

Supports gratuits qui accompagnent la chaîne YouTube : bases de données et SQL, HTML5, CSS3, JavaScript et PHP.
Chaque dossier suit l'ordre des vidéos.

| Dossier | Thème |
|---|---|
| `1-bases-de-donnees/` | Bases de données et SQL (MySQL / MariaDB) — base d'exemple dans `code/` |
| `2-html5/` | HTML5 |
| `3-css3/` | CSS3 |
| `4-javascript/` | JavaScript |
| `5-php/` | PHP et MySQL |

## Comment l'utiliser

1. Regarde la vidéo de la séance.
2. Lis le support PDF correspondant.
3. Fais les exercices du cahier d'exercices.
4. Les corrigés sont ajoutés au fil de l'avancement dans `corriges/`.

## Télécharger

Bouton vert **Code** → **Download ZIP**, ou :

```bash
git clone <URL-de-ce-dépôt>
```

Pour importer la base d'exemple : phpMyAdmin → Importer → `1-bases-de-donnees/code/bibliotheque_lycee.sql`.
